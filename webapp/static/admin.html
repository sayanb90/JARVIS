Jobs

Every entry of the crontab, its state from the job heartbeat, and the tail of its log. Times are UTC.

Log


    

    
State comes from logs/jobs/runs.jsonl, written by data_layer.jobrun around each cron command. untracked means the cron line is not wrapped yet, so only the log's last write time is known. late means the schedule says it should have started and nothing did. stopped means someone stopped the run. Run, stop and restart work only on wrapped jobs and only when JARVIS_JOB_CONTROL=1 is set in .env; each one asks for the admin password again and is written to the viewer's log with your user name. Secrets are hidden in the log tail.
