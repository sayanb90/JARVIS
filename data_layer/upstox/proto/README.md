`MarketDataFeedV3_pb2.py` is the protoc-generated module for Upstox's market data
feed v3, copied unmodified from the official `upstox-python-sdk` 2.30.0
(`upstox_client/feeder/proto/`), which is MIT licensed, Copyright 2023 Upstox.
It is vendored so the project does not depend on the full SDK. To refresh it,
re-copy the file from a newer SDK release and re-run `tests/test_upstox.py`.
